## Working Rules

- Treat the current architecture as approved.
- Reuse existing components before creating new ones.
- Do not redesign completed sections unless a verified defect exists.
- Do not invent product facts, ratings, reviews, statistics, prices, platform support, or government affiliation.
- Interview Mode must remain labeled **Coming Soon** until the product owner confirms release.
- Use plain English suitable for readers whose first language may not be English.
- Keep changes small and phase-specific.
- Run:
  - `npm run check`
  - `npm run build`
- Report only:
  - Summary
  - Files changed
  - Validation
  - Remaining risks
  - Recommendation

Keep the report concise, preferably under 15 bullets.
